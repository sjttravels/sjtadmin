# SJT ADMIN • Operations & ERP Control Center

Official Admin Panel for **SJT Tours & Travels Pvt. Ltd.** (Bengaluru, Karnataka).

---

## 🌟 Capabilities

- **Live Customer Bookings Queue**: Driver assignment, confirmation, status updates, and custom customer messaging.
- **Driver KYC & Document Audit**: Review PSV badges, commercial driving licenses, Aadhaar, and background verification.
- **Driver Attendance & Salary Computation**: Automatic daily KM logs, duty shifts, and payroll generation.
- **Revenue Analytics**: Daily, monthly, and yearly revenue tracking, trip volumes, and net margins.
- **Commercial Fleet Matrix**: Real-time fleet tracking, registration numbers, and vehicle statuses.
- **Financial Accounting Ledger**: Double-entry pay-in and pay-out tracking, corporate invoices, and vouchers.

---

## 🚀 Instant Vercel Deployment

1. Import this repository (`sjttravels/sjtadmin`) into Vercel.
2. Vercel automatically detects Vite settings:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Configure Environment Variables (optional, for connecting to live Voroa database):
   ```env
   VITE_API_URL=https://your-api-domain.com
   ```
4. Click **Deploy**.
